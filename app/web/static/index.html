▸ 发现索引问题时的处理方式

切片切分错误 / 乱码 / 截断异常修复 app/rag/parsers/ 或 chunker.py 后执行 python scripts/reindex_all.py --resume（failed/indexing 文档自动重建，done 且未变文档跳过）
章节摘要缺失 / 质量差摘要为索引时 LLM 生成，限流 429 时降级跳过；配额恢复后对该文档 --resume 重建补全
向量覆盖率不足（SQLite 有块、向量缺失）Embedding 批次失败所致，文档已标记 failed；--resume 自动重建，勿手工改 SQLite/ChromaDB
术语缺失 / 错误检查 term_builder.py 索引页解析（PDF 正则 / EPUB 结构化条目），修复后 --resume
done 文档需强制重建将该文档 rag_documents.status 置为 failed（或改动源文件使 hash 变化）后执行 --resume
